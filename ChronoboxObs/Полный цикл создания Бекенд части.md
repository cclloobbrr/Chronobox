# 1. - Создание проекта
## 1.1. - Создание решения
Для создания API в .NET нам понадобится создать решение.
Заходим в VS и выбираем **Web-API ASP.NET Core**
После чего создадим основу проекта
- В проекте Untitled.API
	- Папка Contracts
	- Папка Controllers
- В проекте Untitled.Application(Библиотека классов)
	- Папка Services
- В проекте Untitled.Core
	- Папка Abstractions
	- Папка Models
- В проекте Untitled.DataAccess
	- Папка Configurations
	- Папка Entities
	- Папка Migrations
	- Папка Repositories

Создание всего того самого

В проекте Untitled.DataAccess создаём файл [[Untitled.DbContext]] 
В него будем подключать наши Entiti
